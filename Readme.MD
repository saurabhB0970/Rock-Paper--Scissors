# 🪨 📄 ✂️ Rock, Paper, Scissors Game

A sleek, interactive, and responsive **Rock, Paper, Scissors** web application built using modern frontend technologies. The game features real-time modular score tracking, dynamic message status changes, and smooth user interactions.

---


---

## ✨ Features

- **Interactive Gameplay:** Simple click controls to choose Rock, Paper, or Scissors.
- **Smart AI Opponent:** Uses a pseudo-random algorithmic choice mechanism for the computer.
- **Dynamic UI Updates:** The status board dynamically shifts background colors based on game outcomes (🔥 Green for Win, 🛑 Red for Loss, 🌌 Dark Blue for Draw).
- **Persistent Score Tracking:** Real-time state management that instantly increments user and computer scores.
- **Modular Codebase:** Written using clean JavaScript ES6+ standards with high modularity for easy updates.

---

## 🛠️ Tech Stack

- **HTML5:** Semantic markup structure for accessibility.
- **CSS3:** Custom styles with modern flexbox positioning and interactive hover states.
- **JavaScript (ES6):** Document Object Model (DOM) manipulation, event handling, and conditional game-state logic.

## 💻 How to Run Locally

Follow these quick steps to get a local copy up and running:

1. **Clone the Repository**
   ```bash
   git clone https://github.com
   ```

2. **Navigate into the Directory**
   ```bash
   cd rock-paper-scissors
   ```

3. **Launch the Game**
   - Simply double-click the `index.html` file to open it in any modern browser.
   - *Alternative:* Right-click `index.html` and use the **Live Server** extension in VS Code.

---

## 🎮 How to Play

1. Click on one of the choice buttons (**Rock**, **Paper**, or **Scissors**).
2. The computer will instantaneously make its automated choice.
3. The dynamic message box will alert you to the round outcome.
4. Your running score will automatically increment on the scoreboards!
